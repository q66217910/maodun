# 矛盾分析室

把一个纠缠着很多因素的现实问题，拆成结构清楚、能下手、可检验的判断。

它不负责给建议，负责让你看清结构。所有结论都要落到动作上，动作都要能被验证。

> 一堆矛盾里，只有一条在牵着别的走。

零依赖，纯 Node.js 内置模块；前端是原生 HTML/CSS/JS；模型自备（BYOK），Key 只存在你本机浏览器里。

---

## 它做什么

输入一段处境描述（和谁、在什么场景、卡在哪个环节、试过什么），输出固定十段结构的拆解。这个顺序本身就是推理链条：看事实 → 看结构 → 定主次 → 定性质 → 定阶段 → 谈条件 → 落到动作。

| 段落 | 要解决的问题 |
| --- | --- |
| 1. 判断 | 最多三句，直接说真正的卡点。你以为的问题不是真问题时，在这里点破 |
| 2. 事实清点 | 分「已知」与「待核实」。待核实必须写成：查什么 / 问谁 / 两种结果各把结论推向哪边 |
| 3. 矛盾清单 | 表格五列：矛盾 / 对立的两方 / 性质 / 当前态势 / 主次 |
| 4. 主要矛盾 | 是哪一条、为什么、依据是什么。证据不足就写"暂定" |
| 5. 主要方面 | 哪一方占主导、在增强还是削弱，以及**两方为什么离不开彼此** |
| 6. 阶段 | 量变积累、临近转折，还是已进入新阶段。不同阶段策略差在哪 |
| 7. 内因与外因 | 内因是能改变的，外因是只能应对的（不给虚假掌控感） |
| 8. 转化条件 | 主次在什么条件下易位；哪些现在能推，哪些只能等 |
| 9. 行动 | 三步，每步含「做什么 + 检验标准 + 若结果相反说明什么」 |
| 10. 可能的误判 | 2–3 条，指出你最容易骗自己的地方 |

方法底座是八条：没有调查就没有发言权、抓主要矛盾、看矛盾的主要方面、矛盾的同一性、对抗性与非对抗性的区分、发展阶段、内因与外因、认识回到实践检验。另外补三条容易漏的——弹钢琴（别把别的全丢）、抓典型（第一步先小范围试）、从最坏处准备。

### 几个刻意的设计

- **矛盾不等于敌人。** 日常处境里绝大多数是非对抗性矛盾，双方还得在同一个统一体里待下去。工具不会建议"彻底切割"作为首选，除非同一性已实际破裂。
- **行动必须是回填接口。** 每步都要求写「若结果相反，说明哪条判断错了」。没有这一句，行动只能勾完成，无法修正认识。
- **报告自带质检。** 模型跑偏时用规则兜住：缺段、顺序错、矛盾清单不是 3–5 条、没判对抗性、主要方面没写依存点、行动没给检验标准、第一步没写时限、没写「最低限度运转」和「最坏情况」，都会在报告下方标出来。

## 快速开始

需要 Node.js 18 或更高（用到了内置 `fetch`）。

```bash
node --version   # 应 >= 18

git clone https://github.com/q66217910/maodun.git
cd maodun
npm start        # 等价于 node server.js
```

Windows 上也可以直接双击 `start.bat`，它会检查 node 并自动打开浏览器。

打开 <http://localhost:3000>，点右上角齿轮填模型：

| 项 | 说明 |
| --- | --- |
| 接口地址 | 兼容 OpenAI `/chat/completions` 的完整地址，如 `https://api.deepseek.com/v1/chat/completions` |
| 模型名称 | 如 `deepseek-chat`、`gpt-4o`、`kimi-k2` |
| API Key | 只写入本页面的 `localStorage`，不会经过服务端保存，也不写日志 |

对话框里有 DeepSeek / OpenAI / Moonshot 的快速填充。任何 OpenAI 兼容接口都能用。

## 配置项

全部通过环境变量，都有默认值，不配也能跑。

| 变量 | 默认 | 作用 |
| --- | --- | --- |
| `PORT` | `3000` | 监听端口 |
| `MAODUN_HOST` | `127.0.0.1` | 只绑本机。设成 `0.0.0.0` 才允许局域网访问（同时把本机的转发能力也暴露出去，想清楚再开） |
| `MAODUN_ALLOW_PRIVATE` | 关 | 允许 `/api/analyse` 转发到内网或回环地址。连 Ollama / LM Studio 等本地模型时设 `1` |
| `MAODUN_SKILL_DIR` | `<工程根>/skills/contradiction-analysis` | 提示词目录位置 |

连本地模型的例子：

```bash
# macOS / Linux
MAODUN_ALLOW_PRIVATE=1 node server.js

# Windows CMD
set MAODUN_ALLOW_PRIVATE=1 && node server.js
```

│   ├── markdown.js                 渲染层：Markdown → DOM、分段抽取、报告质检（UMD，Node 可测）
│   ├── style.css                   视觉系统：纸 + 朱 + 靛
│   └── demo.md                     首页「看一份示例」用的样张
├── skills/contradiction-analysis/
│   ├── SKILL.md                    方法说明、边界、失败模式、版本记录
│   └── references/

界面分三个视图：**提问**（写处境、看拆解、追踪行动）、**我的分析**（历史案卷，逾期行动会标红）、**方法**（这套拆解从哪来）。

## 提示词与代码分离

代码里不存任何提示词文本。运行时 `server.js` 从 `skills/contradiction-analysis/references/` 读取，前端通过 `GET /api/prompts` 取回再拼进 `messages[0]`。

所以：

- 改提示词只改 `.md`，不碰代码，**刷新页面即生效**，不用重启服务。
- 版本号只在 `SKILL.md` 的 frontmatter 里维护一处，其他地方都从那里读。

代价是改结构要成对改：如果「行动」或「事实清点」的写法变了，前端 `SECTION_MAP` 与 `syncChecks` 也要同步，否则分段渲染和「待核实」工单会失效。

## 接口

只有两个，都是给页面自己用的。

### `GET /api/prompts`

返回两份提示词、一级小节标题（供前端校验结构）、skill 目录与版本号：

```json
{
  "analysis": "...",
  "followup": "...",
  "sections": ["判断", "事实清点", "..."],
  "skillDir": "...",
  "version": "1.2.0"
}
```

### `POST /api/analyse`

把模型请求转发出去，绕开浏览器跨域限制，以 SSE 流式回传。

```json
{
  "endpoint": "https://api.deepseek.com/v1/chat/completions",
  "apiKey": "sk-...",
  "model": "deepseek-chat",
  "messages": [{ "role": "system", "content": "..." }],
  "temperature": 0.6
}
```

上游返回的错误会转成 `{"message": "..."}`；流式中途断掉会发一帧 `{"error": {"message": "..."}}`，已经收到的内容保留在页面上。

## 安全边界

这个服务天然是个"帮别人发 HTTP 请求"的能力，所以几处默认值是刻意收紧的：

- **只绑 `127.0.0.1`。** 要开给别的设备，必须显式设 `MAODUN_HOST=0.0.0.0`。
- **`/api/analyse` 不当代理。** 默认拒绝指向私有网段、回环地址、CGNAT、链路本地与组播的 endpoint，且对域名做 DNS 解析后逐条校验——否则它会变成内网探测器。域名解析结果缓存 60 秒。
- **同源校验。** 带 `Origin` 的请求必须与 `Host` 同源，挡住别的网页借用你本机的转发能力。
- **静态托管白名单。** 任何以 `.` 开头的路径，以及 `skills/`、`tests/`、`node_modules/` 一律 403。提示词和项目笔记不对公网。
- **请求体上限 512 KB。** 超时拆成"连接 30 秒 + 空闲 90 秒"，空闲计时每收到一块数据就重置。
- **Key 不落盘、不进日志。** 只在单次请求的 body 里透传。

## 测试

```bash
npm test           # 渲染与质检单测
npm run test:e2e   # 转发链路：起一个假上游，验证流式、错误帧、超时与私网拦截
```

`assets/markdown.js` 是 UMD 的，浏览器挂 `window.MaodunMd`，Node 里能直接 `require`，所以渲染逻辑可以脱离浏览器测。

## 它不做什么

- 不替你决定人生，不评判你的对错。
- 不给医疗、法律、严重心理危机的具体处置意见。遇到这些，请找专业机构。
- 不套模板。同一类问题，事实不同，结论就应该不同；给放之四海而皆准的正确废话是这个工具最想避免的失败。
